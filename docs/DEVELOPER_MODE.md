# 开发者模式 · v0.6

用于快速搭配、跳转关卡和复现 Bug。无需浏览器控制台或 `?debug=1`：首页、暂停 / 商店 / 结果面板都有入口；战斗中点击左上角「开发者模式」，或随时按 **F2**。F2 / Esc 关闭面板。

## 推荐流程

1. 打开「关卡 / 工具」，选择地图、波次和整数种子。按需开启免伤、技能无冷却、停止敌人 AI 或调整时间倍率。
2. 在「技能 / 装备」先选 Q/W/E/R 槽，再点击技能。已装备技能会与所选槽交换，保持四槽无重复。装备按钮循环切换空槽及所有对应装备，无需金币购买。
3. 在「海克斯 / 增益」分页勾选任意组合，也能全选 / 清空。这里不按当前技能过滤；缺少触发技能的增益保持休眠，便于排查组合条件。
4. 点击「应用并进入关卡」，直接以满生命生成选定波次，省略商店和前面的战斗。战场持续显示 **DEV**。
5. 需要重复同一场景时，用「重测已应用配置」。要恢复正常流程，点击「退出测试 → 普通首页」。

面板配置是草稿，修改不会立刻改变正在测试的角色。**应用会重建关卡**，清除当前生命损耗、弹体、状态、触发计数和冷却等现场；关闭面板只收起编辑器。技能页的「读取当前关卡与搭配」可以用当前实际构筑覆盖草稿。

## 即时测试工具

面板打开时冻结战斗。已应用开发者配置后，可以对当前现场立即操作：

| 工具 | 行为 |
| --- | --- |
| 满血 / 复活 | 恢复生命、清除玩家负面状态和护盾，死亡后可继续当前测试。属于调试设置，不触发治疗海克斯。 |
| 生命设为 25% | 快速准备低血量场景；不伪造受伤事件。需要触发黎明使者时，关闭免伤并让敌人实际攻击。 |
| 刷新冷却 | 立即清空技能剩余冷却与普攻间隔，不清空海克斯内部触发计时。后者可通过重测配置重置。 |
| 清空敌人 | 移除敌人及其在场弹体，不发击杀事件、金币或奖励。测试模式中清场后仍留在当前关卡。 |
| 步进 1 帧 | 面板保持打开，实际推进一次 1/30 秒逻辑；不受时间倍率影响。死亡状态下需先复活。 |
| 在周围生成 | 从敌人注册表选择类型，每次生成 1 或 5 个，使用所选波次的生命倍率；检查地图、玩家和其他角色的占位。总实体上限 128，空间不足时只生成可放置的数量。 |

测试开关在应用配置时生效：

- **玩家免伤**：承受伤害为零；不伪造受伤事件。命中附带的减速等状态仍可观察。
- **技能无冷却**：技能施放后的冷却为零；普攻保持装备与增益的正常攻击节奏，冲刺进行中不能重复冲刺。
- **停止敌人 AI**：敌人停止寻路和攻击决策；已飞出的弹体、附着状态和玩家攻击继续按正常模拟更新。
- **时间倍率**：0.25× / 0.5× / 1× / 2×；逻辑仍固定 30 Hz，通过模拟推进速度缩放，不改变单步伤害和碰撞算法。

测试关卡不会因清场自动进入奖励或下一波，需要在面板选择并应用其他波次。普通模式的三选一、经济、波次推进与两种操作方式保持原流程。

## 保存与复现

「预设 / 复现」提供 **3 个本机存储槽**。保存和载入均需主动点击；载入只修改草稿，之后点击应用。刷新游戏不会自动启用开发者模式或作弊开关。浏览器禁用 / 清除本地存储时，预设可能不可用，可改用文本导出。

「导出当前待应用配置」生成可复制的 JSON 文本；点进文本框全选复制，粘贴到其他电脑的同一面板后点击「导入文本为待应用配置」。导入先完整校验版本、种子、地图、波次、技能、装备槽、增益及开关；错误配置不替换原草稿。

配置携带：`version / seed / mapId / wave / loadout / perks / equipment / options`。相同版本的游戏、相同配置与相同输入顺序，可以重复生成同样的初始关卡与战斗结果。

**这是初始场景配置，不是中途存档或输入录像。** 报 Bug 时请一起提供配置文本、操作步骤、预期与实际表现，以及代码提交版本。跨版本内容改动可能改变敌人、数值或随机行为；已删除的内容 ID 会拒绝导入。

## 代码扩展

- `simulation/DeveloperConfig.ts`：配置版本、拷贝、严格解析、本地存储读写。只存数据，不执行文本。
- `platform/LocalTransport.ts`：面板开关、草稿 / 已应用配置、冻结调度、重建与退出。普通命令在面板中被隔离；测试动作要求已经显式应用配置。
- `simulation/GameWorld.ts`：带开发者选项的新世界才处理免伤、无冷却、跳波、生成和即时工具；普通世界拒绝测试动作。
- `render/DeveloperPanel.ts`：地图、波次、技能、装备、海克斯和敌人均枚举内容注册表。技能 / 海克斯有分页，新增内容不需另写按钮。
- `input/InputController.ts`：F2 与面板键盘隔离，防止文本输入被解释为施法或奖励选择。
- 新 `.meta` 由 Cocos Creator 导入生成，和源码一同提交。

验证：`pnpm check`、构建后 `pnpm test:developer`。新增测试覆盖普通模式隔离、配置校验、固定步进、重新生成、存储、导入导出、真实文本框 / 键鼠和窗口缩放。
