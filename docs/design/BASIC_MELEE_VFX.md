# 初始普通近战攻击：基础弧与元素分层

用户已选择v7作为生产方向：[白色基础效果](../../art-source/basic-slash-v7/white-study.png)、[12个关键状态](../../art-source/basic-slash-v7/keyframes.png)。基础效果为白色，宽厚、斜圆钝、最亮最显眼的当前斩头继续保留，旧轨迹逐渐细、暗、透明；不能恢复尖月牙或板状平切面。

2026-10-21：用户否定 runtime-v1 / v2，并明确选择“按定稿环扫，并同步修改判定”。当前[运行版 v3](../../art-source/basic-slash-runtime-v3/README.md)直接采样这张原稿的12格，关键时刻保持原画，帧间对齐亮锋位置进行混合；伤害随亮锋的世界多边形扫掠结算。旧117°完整扇区、灰色范围底板和另一张弯曲光流已移除。本页以当前实现为准，不代表用户已批准新实机观感。

## 核心造型

沿鼠标方向挥扫；v7图板用右下→右侧→右上→上方→左上的运动方便对照参考头型，实际播放随输入朝向整体旋转，并使用同一相位的世界亮锋轮廓。**当前挥击刃口最粗、最亮，刚经过的轨迹较细较暗，更早的轨迹继续变细、变暗、变透明。** 亮锋跟随动作位置移动，不能让整圈外缘同时纯白，也不能只给整张弧同步降低透明度。没有固定外显武器时，以动作相位中的视觉刃口表达当前位置；这不新增装备贴图、身体挂点或独立碰撞。

这里把用户所说的“末尾”统一称为“当前端”，指武器现在到达的位置；“最旧端”指挥动开始时留下的轨迹。当前端宽厚、白亮、有实际面积，鼻端按用户圈选参考形成饱满的斜圆钝轮廓；不能收成针尖，也不能用几何直线截成板状平面。稍错开的发光层从斩头接入弧形拖尾，向旧端逐渐收细。宽度比例是辅助，头型以用户圈选的具体形状优先，不为套公式重新设计。

内部使用长短、宽窄不同的顺向光流、交叠薄面、少量局部切光和透明通道。细节顺着同一次挥动，集中在较新的轨迹；不是随机花纹，也不是2–3条等宽平行色带。外缘仍连续、曲率稳定、边界清楚，不添加倒刺和飞散小块。尾迹可以很薄很透，但新生斩面保留宽度与冲击；人物脚底与头部可见，不填满整个攻击扇区。

粗像素风同样需要强特效。力量来自“短促亮锋 + 有厚度的新生轨迹 + 丰富的内部光流 + 旧轨迹快速衰减”。像素曲线可以用有序阶梯拟合，在实际显示尺度上读成流畅刀光；不刻意加大锯齿或用模糊掩盖毛边。主弧周围默认保持干净，粒子与命中爆点另层制作。当前按用户确认保留原稿环绕形状，不增加符文；环绕尾迹不等于整圈同时伤害。

## 亮度与透明度沿轨迹变化

以下为待制作样张的起点，不是当前引擎已生效的值：

| 轨迹年龄 | 形态和光线 | 不透明度示意 |
| --- | --- | --- |
| 当前刃口 / 最新短段 | 宽厚斜圆钝斩头，局部白亮芯占有实际面积；高亮集中在用户圈选式头部 | 约100% |
| 紧随其后的新轨迹 | 从当前端开始收窄，中性银白叠层，内部流线与透明通道清晰 | 约65–80% |
| 较旧轨迹 | 中性灰光流逐渐拉薄，减少亮细节，地面可透出 | 约25–45% |
| 最旧尾端 | 少量暗流线渐隐，最后消失 | 约5–15%至0 |

这些值沿挥动路径分布，可以连续插值或用足够细的透明层次表达，不能只横跨弧的厚度分成同心色带。硬边意味着边界明确，不要求整张刀光alpha=1；不要画成黑色不透明尾巴或用散点抖动制造假透明。制作RGBA时将亮度、元素染色和alpha分别考虑，亮锋保持局部对比，旧尾迹真实透底。

默认近战按用户要求使用中性白与灰：白亮芯 `#FFFFFF`、银白 `#D8D8D8`、中灰 `#929292`、暗灰 `#424242`可作生产起点，不作为概念PNG已严格限色的声明。辉光同样不染粉、紫、蓝或黄，旧尾迹靠alpha透底。火、冰等配色以后单独映射；人物衣料配色与攻击元素相互独立，蓝衣玩家也可以打出火属性效果。

## 12个关键状态

时刻从本次攻击开始算。当前 `content/attacks.ts` 中默认挥砍前摇0.12秒、生效0.12秒；高攻速时 `GameWorld.attackToward` 会缩短实际相位，下表是普通速度示意，不写死替代模拟数据。

| 状态 | 参考时刻 | 画面 | 作用 |
| --- | --- | --- | --- |
| 01 蓄势 | 0 ms | 不画斩弧，本体回收手臂、转体蓄力 | 留出出手对比 |
| 02 压紧 | 80 ms | 极暗的起手短痕迹 | 不能提前出现完整亮刃 |
| 03 出手 | 120 ms | 右下出现宽厚亮锋，后方初生短尾迹 | 对齐实际生效起点 |
| 04 挥扫 | 144 ms | 亮锋移至右侧，右下旧轨迹衰减 | 不留下第二个白亮斩头 |
| 05 推进 | 168 ms | 亮锋到右上，旧轨迹向下接续 | 厚端跟随当前位置 |
| 06 峰值 | 192 ms | 亮锋经过上方，重叠亮面完整 | 保持头型与内部细节 |
| 07 随挥 | 216 ms | 亮锋到左上，形成参考式斩头 | 旧弧不能整段等亮 |
| 08 停止出锋 | 240 ms | 新亮锋消失，留下灰色光流 | 对齐有效期结束 |
| 09 余波 | 270 ms | 灰色余迹减弱 | 不继续转动或生成新亮头 |
| 10 淡出 | 300 ms | 只留很淡的弧形薄层 | 不散成外部粒子 |
| 11 残迹 | 330 ms | 接近不可见的短残迹 | 准备回收 |
| 12 清空 | 360 ms | 效果完全消失 | 回收显示实例 |

这是非均匀关键时刻；不能把12格简单以固定FPS播放后仍声称时序一致。接入时02映射前摇约2/3处，03–07映射实际有效期的0%、20%、40%、60%、80%，08映射有效期结束；09–12为尾迹余留阶段的25%、50%、75%、100%。普通余迹最多约0.12秒，高攻速时优先缩短装饰尾迹。高攻速由实际相位重新映射时间，不丢弃中间碰撞路径。用户已授权此次改变判定，后续美术修订不得自行变更玩法范围。

**当前只对移动亮锋及其两次模拟更新之间的路径进行判定。** `MELEE_BLADE_KEYS` 定义归一化世界轮廓，`MeleeSweep` 插值并细分扫掠，`CollisionWorld` 查询目标体积和遮挡，`CombatEngine` 结算。内部空洞和已经暗下来的旧轨迹不会继续命中；同刀同目标最多一次，结束余迹完全无伤害。不再用整块范围底板暗示不可见区域也有效。F3 同时显示当前亮锋和上一模拟步覆盖的区域。轮廓是独立内容数据，不在运行时读取图像像素或等待动画回调才造成伤害。

## 复用层次

| 层 | 共享内容 | 元素可改变内容 |
| --- | --- | --- |
| 基础斩弧 | 亮锋、内部光流、轨迹alpha、固定原点、朝向、半径和相位 | 灰度 / 亮度分区映射元素颜色，保留原alpha与局部白亮锋 |
| 有效范围表达 | 当前亮锋对应的清晰外形；旧轨迹明显减暗、变透 | 可以染色，不得把旧轨迹重新点亮成看似有效的第二道刃口 |
| 装饰粒子 | 发射区域、粒子池、生命周期管理 | 形状、颜色、方向、速度、少量数量差异 |
| 命中反馈 | 由真实命中事件触发的小爆点 | 短火花、冰屑或暗色裂片 |

同一套基础弧贴图即可变换不同元素，不为火 / 冰 / 黑暗分别复制全套弧动画。灰度映射保留亮锋、内部流线和轨迹alpha，不再强制把所有细节压成3条平行色带。默认无外围碎片；v7先完成中性白整体与12状态设计，旧版元素对照不代表当前透明光流已完成元素生产。

| 外观提案 | 基础弧配色 | 额外粒子行为 |
| --- | --- | --- |
| 中性 | 灰白 → 石灰 → 深灰 | 默认0个外围粒子，完整拖尾缩短淡出 |
| 火 | 奶白 → 橙 → 砖红 | 基础弧为0；后续可试命中处1–2簇短火星，不沿整个外缘散布 |
| 冰 | 冰白 → 冰青 → 深蓝 | 基础弧为0；后续可试命中处1–2片冰屑，基础斩面不长出冰刺 |
| 黑暗 | 淡灰紫亮边 → 紫灰 → 炭黑 | 基础弧为0；后续可试命中处少量内收碎片，不铺黑雾或撕裂外缘 |

这些数量是待验证的初始预算，不是已测性能容量。共存多个元素时先选择一个主弧配色，其余用少量次级粒子 / 命中反馈表达；上限由表现层统一控制，不叠加数条完整高亮斩弧。主元素优先级由后续机制配置明确，不能擅自用装备类别或购买顺序决定。

外观不自动赋予灼烧、减速、吸血或改变伤害类型。玩法效果仍通过属性、余烬与 CombatEngine 定义。攻击挥空仍有完整斩弧，但没有命中爆点；多目标命中的装饰可限量，实际伤害事件不可因此合并或丢弃。

## 打击感配套（命中爆点已接入，其余待实现）

静态斩面只能表达形体；最终需要动作、真实命中反馈与声音在同一事件上配合：

- **出手**：本体先压紧再快速转体 / 伸臂；脚底有支撑，不能只晃整个精灵。初版关键图中的人物用于尺度示意，不能直接当作已验收的身体攻击动画。
- **命中爆点**：仅由真实命中事件触发。接触处先出现短白亮楔 / 星形破口，再向攻击方向散出几簇碎片，约0.06–0.12秒内结束；空挥不出现。爆点独立于基础斩面，允许元素配色复用。
- **短暂停姿**：可试约30–40毫秒的本地攻击者 / 受击者视觉姿势保持；不停止GameWorld、移动输入、联网时钟、碰撞或伤害。斩弧有效区仍服从模拟相位，不能为停姿延长亮刃寿命。密集多目标命中合并 / 限频，不能累计冻结。
- **受击与镜头**：敌人局部明暗变化、身体受力姿势与很小的短震动共同表达重量。角色逻辑位置不因表现偏移改变；真正击退必须另经玩法机制。震动应可关闭并按像素对齐，联机仅影响对应本地视角，不向全员广播镜头偏移。
- **声音**：出手的短促破风与命中的低频实体声分开，命中时加一层清脆短瞬态；没有命中就没有实体撞击声。多目标限并发，避免同帧音量叠爆。

当前已接入真实近战命中的短白色爆点；本体精修、短暂停姿、受击增强、镜头与声音仍待ART-15。不能以斩击和爆点已接入声称音频或身体帧已经重制。

## 空间、资源与接入约束

### 任意方向：一套图集连续旋转

特效采用一个标准朝向的整套动画，共用纹理，按鼠标发起的攻击方向连续旋转0–360°，不复制八套特效图集，也不把特效朝向取整到八方向。角色本体仍使用已有五绘制视角 / 三镜像的八方向动作，不能把人物精灵整张旋转；人物方向与刀光方向分别消费同一次攻击的信息。

- **角度**：使用本次 `Swing.facing` 转为屏幕方向，再以 `atan2` 求角度，减去源图的标准朝向角。不能直接把世界角当屏幕角；现有 `GroundPlane / GroundProjection` 有方向变换。当前固定窗口356×282、原点(178,138)、参考半径180、标准瞄准朝向屏幕向上；见运行版制作记录。
- **支点**：以真实攻击中心对应的共同原点旋转，不以当前帧的bbox中心、最亮位置或贴图边缘为中心。所有切片恢复到同一源坐标系，缩放由世界半径与统一投影决定，禁止逐帧贴合bbox。表现偏移与旋转应分清局部 / 屏幕坐标，避免固定屏幕偏移变成某些方向的脱手。
- **投影**：当前地面是正交单位基与统一缩放，允许直接旋转标准朝向的特效。图片与世界亮锋使用相同刚性旋转和等比缩放。原画曲线自身不是正圆，但不能因此压缩地面、改变某一方向速度或把鼠标输入做方向补偿。
- **挥动与瞄准**：动画内部表现亮锋从起点走到终点；整体旋转只决定这次挥击朝向。攻击发起后使用固定的 `Swing.facing`，不逐帧追随最新鼠标把整刀或旧尾迹拽向新方向。后续新攻击可以使用新的鼠标方向，结束尾迹保留最后合法位置和角度。
- **拖尾 / 粒子**：图集中的亮锋与旧轨迹整体共用旋转。独立粒子若增加，发射点和初速度也从同一个局部坐标系转换；发射后按自己的生命周期运动，不再跟随鼠标旋转。
- **验证**：八个主方向之外至少检查22.5°等中间角及连续转向，检查偏心、裁切、亮度和像素闪动。任意角度旋转仍会发生像素重采样，不能以“最近邻”声称所有角度像素网格一致；用真实游戏倍率验证边缘质量，不通过将瞄准锁定到八方向解决。

当前普通攻击使用 MeleeVfxPlan / MeleeVfxView：共享原稿纹理与 melee-keyframes 材质，按非均匀关键时刻采样。固定支点连续旋转，地形 Stencil 限制可显示区域；遮罩本身不参与伤害。旧技能翻页保留，普攻不走旧4帧播放器。RGB 黑底的运行时白光合成与帧间插值见[运行版 v3](../../art-source/basic-slash-runtime-v3/README.md)。

### 世界范围与资源生命周期

- 取 `Swing.center / facing / radius / arc / windup / active`，不是由人物图片大小、武器图片或鼠标距离推算。朝向在攻击发起时确定；有效期中心按当前模拟规则跟随角色。
- 基础射程仍为5，实际半径读取单位 attackRange；`arc=π×1.7` 只记录近似环绕尾迹幅度，不能据此构建完整伤害扇区。实际命中以 MeleeSweep 的多边形为准。
- 外缘尺度读取实际范围，不靠缩放整弧制造扩圈。当前亮锋有内缘，角色附近存在真实空洞；更近不自动代表能命中。旧尾迹不反复伤害后来走入的目标。半径和地形遮罩不能被当作整圆判定。
- 本次源图原样保留，通过 MELEE_ART 的固定 UV 窗口排除标题与格线。不可重新裁到不同中心、按 bbox 缩放或用程序曲线替换原图的内部细节。
- 01/12为空效果状态，运行时隐藏节点；中间状态按非均匀时刻播放。渲染帧间插值不等于新画了60张手绘帧，也不改变30 Hz权威模拟。
- 当前基础弧保留RGB原稿，由材质运行时提取白光alpha；不把它称作已恢复原始alpha的透明图集。采样结果不含人物、地面、文字、十字或箭头。未来独立新素材仍优先制作真实透明背景。人物保持整身帧。
- 全部使用模拟时间；暂停冻结、切图 / 重开清理、死亡 / 中断取消。尾迹保存最后的合法朝向与位置，不能在攻击结束后继续拖着角色跑。纯装饰随机不能消耗战斗随机流。
- 亮锋相位和攻击中心必须与单位位置一起在上一已结算状态到当前状态之间插值；禁止外推下一模拟步的刀光角度。否则即使旋转公式相同，画面也会比命中提前最多一个固定步。F3 的亮锋实线使用同一显示相位，历史扫掠淡线另画，不能把最新模拟轮廓当作插值后画面的当前轮廓。
- `PixelVfxPlan / PixelVfxView` 为4帧每0.1秒的装饰翻页，不承担新普攻。MeleeVfxTimeline按sourceId / Swing.id维护连续近战表现，真实伤害cue携带sourceId / attackId关联命中，Swing结束后保留短暂低亮余迹。
- 优先复用现有快照和碰撞查询。友方斩弧与粒子须让出敌方危险边界，低亮尾迹先降级；不删除实际弹体、预警或仍在生效的攻击范围识别层。多个元素仍归同一装饰预算，不能每个元素分别拿一套完整预算。

## 验收与后续工作

原稿关键帧、当前亮锋和旧尾迹需分别检查，不能用一张峰值截图代表整段动画。关键时刻的素材像素保持原稿；去黑底合成会影响最暗细节及浅底对比，检查实际战斗倍率下的清晰程度。中间角度、地形遮挡、空洞、移动中的扫掠、防重复命中与暂停 / 重开均需验证。

本轮记录见[运行版 v3](../../art-source/basic-slash-runtime-v3/README.md)。火 / 冰 / 黑暗、四人压力、严格像素网格及身体动作 / 停姿 / 声音另行完成；不以逻辑测试数量声称美术观感已获用户认可。
