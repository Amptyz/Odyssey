## 1. 六栏、交易与状态模型

图标设计已补齐当前全部 18 件：[武器 / 衣甲 / 头饰草图](../../art-source/design-sketches-v1/README.md)，每类六项。它们是带底色和说明的设计板；透明小尺寸图标、纸娃娃穿戴资源与动作接入继续由 ART-01 制作，不改变本文件的六栏及外观规则。

### 1.1 无类型占位限制

- 每个玩家有6个有序通用位置，位置键slot1至slot6；`equipped[slot]` 为装备ID或空。任何武器、身体、头部物品都可占任一空位，可以同时装备6件武器、6件身体或6件头部。`category: weapon/body/head` 只供描述、外观及攻击配置使用，不限制购买或穿戴。
- 首批**同ID本局只购1次、同ID最多穿戴1份**。不同ID即使同category也可相加属性。没有两把相同赤铜剑、叠同件价格成长、第二份残缺效果或隐藏“同类装备折扣”。若以后要求同ID复购，必须升级为itemInstanceId、重新算重复组合与唯一组，不能用重复ID数组悄悄开放。
- 每个玩家持有独立AttributeSet。六栏属性来源为 `equipment:<slot>`（如 `equipment:slot1`），槽键slot1..slot6；它替代旧语义的 `equipment:weapon/body/head`。权威玩家归属在PlayerState/AttributeSet，不把不同玩家装备放入共享来源表。移除/重算按来源替换，不对最终结果反复加减。
- 全部6件的modifiers生效；没穿戴的库存物品不提供任何属性、被动或外观。头部不能因为当前未显示其图片就失去属性。

建议权威数据（字段名可按父任务实现保持一致，语义必须等价）：

```text
inventory: EquipmentId[]                  // 已购唯一ID，保留旧物，不退款
equipped: Partial<Record<EquipmentSlot, EquipmentId>> // slot1..slot6，空栏缺省，禁止重复同ID
purchaseOrder: EquipmentId[]             // 已成功购买的严格顺序；每ID仅出现一次
purchaseSerial / purchaseRankById         // 可由purchaseOrder推导，不接受客户端任意伪造
```

库存顺序本身若已保证“成功购买时append且永不排序”，可直接作为purchaseOrder，避免保存两份可能不一致的真相。checkpoint必须保留该顺序；恢复时不得按ID排序。F2配置使用显式purchaseOrder，缺省按配置中equipment列表顺序，UI注明右侧/末项最新；不能依赖对象键枚举推测玩家购买顺序。

### 1.2 购买、满栏替换与库存换装

1. 买新ID时先验证shop阶段、权威playerId、合法ID、未拥有、余额及目标位置。未满时未指定位置就用最小空索引；指定已有装备的位置视为显式替换。
2. 已满且没指定replaceSlot：拒绝、不扣金币、不改变购买顺序；UI让玩家先选要替换的一栏。不能默默替换“最旧装备”或让付钱后没有有效装备。
3. 所有检查成功后，扣价→加入库存与购买顺序→放入目标栏。旧装备回已购库存；不卖出、不退款、无额外扣款。整个事务原子提交；客户端重发同ID购买不能重复扣款。
4. 库存换装免费，仅shop允许。已在其他栏的同ID拒绝重复穿戴；本稿不自动移动以免一个操作同时空掉另一栏。换装不会更新purchaseOrder，不等于再次购买。卸装可留下空位，也不修改历史购买顺序。
5. 最大生命改变只截断超上限当前HP，不因装备/换装回血；第一关开始补满，后续阶段恢复沿现有30点。重开清所有库存、购买顺序、装备与临时状态。玩家间独立余额、库存、位置、顺序与被动CD。

## 2. 最后购买与外观

“最后”按**成功购买的权威顺序**，不按装备栏编号、最近点击的预览、装备动作或客户端时间。这里只在当前已装备集合中寻找最新者；卸掉最新物品时回退到仍装备的次新物品，库存不操控战场外观。

**外观已确认按部位取最新：** 从当前装备里分别选购买顺序最新的weapon/body/head决定已有纸娃娃三层；同部位旧件隐藏但属性保留。没有该部位装备则显示中性基础人物对应层。购买新头盔只更新头部，身体/武器照其各自最新者。

**2026-10-19 规则更新：装备与普攻形式完全解绑。** 默认普攻为 `slash` 近战挥砍（5格），增益 `missileAttack` 可改成 `missile` 飞弹（15格）。装备的 category、外观和购买顺序都不提供普攻身份或射程。多武器仍叠加各自属性和被动，但不附带额外挥击或弹体。未来形式继续通过增益扩展，详见 [内容指南](../CONTENT_ARCHITECTURE.md#普攻与命中体积)。

普攻本体均为 `1×总AD` 物理伤害，包括增益转换的飞弹外观；无AP普攻系数。AD/AP/施法者生命表达式出手/发射采样；暴击资格/概率/倍率、穿透、吸血与目标双抗/护盾在命中时读取，与STAT-02一致。基础暴伤2；普通本体可暴击、触发攻击特效及合格全能吸血，方向仍为鼠标地面、允许挥空、不锁敌。

## 3. 经济、六件预算与阶段节奏

18件**统一100金币**；不再沿用武器100/身体60/头部40。旧价格在无类别上限时会让便宜头部提供显著更快的六栏成型，故同价再以属性/形态/被动区分。每件约承担六件预算的1/6；category不是强度或稀有度等级。

五关两图的拟定流程：四个普通关卡后各开店，第5关Boss。保持现有 `startingGold=160`、`waveGold(w)=100+20×(w−1)`，不按怪数量额外发钱。

| 进入阶段 | 累计金币 | 可拥有并装备件数上限 | 全买100件后余额 | 约定 |
| --- | ---: | ---: | ---: | --- |
| 1，开局店 | 160 | 1 | 60 | 任意选1件，不能假设有旧版剑+板 |
| 2，过1关+100 | 260 | 2 | 60 | 再买1件 |
| 3，过2关+120 | 380 | 3 | 80 | 再买1件 |
| 4，过3关+140 | 520 | 5 | 20 | 可连续买2件，迎来明显成型提升 |
| 5 Boss，过4关+160 | 680 | 6 | 80 | 六件总价600；80不能额外买第7件 |
| 最终奖励/胜利，过5关+180 | 860 | 不再买 | 不纳入Boss前预算 | 不能声称Boss前拥有860 |

该经济意味着正常五关里全买装备的玩家**通常无法再付100换买第7件**；满格替换流程仍须实现并可用F2/库存回切验收，不能把“Boss前额外480用于换装”这一旧三槽解释保留。玩家可以少买并保留金币，但未拥有的装备不能免费试穿。未来若要普遍支持满配后的改构筑，需要额外商店/退款/收入变更，属于另一个明确设计，不能靠售卖文案伪装当前可达。

短版3/2波地图若暂保留：Boss前只有380/260，最多3/2件100装；其旧200三槽成型与数值基准作废。必须随五关地图上线或重新平衡短图，不能只换装备价格后宣称旧关卡手感不变。

预算检验不套LoL金币换算：用单件、2/3/5件曲线，以及所有18选6共18,564组无重复组合的输出/双抗EHP包络；价格统一后没有廉价头部塞满的套利。纯输出没有免费高生命，坦克放弃AS/暴击/AP；所有类型都允许混合，但同类6件不能默认触发“套装加倍”。

## 4. 18件完整定义

表格是数值设计清单，**不是可复制的旧stats JSON**。每条数值转为统一modifiers：固定点数用flat，AS/MS比例用percent；急速是点数，暴击/全能吸血用小数。`category`只作分类，`price=100`、`maxOwned=1`、`maxEquipped=1`对全部18件相同。未列属性=0。

普通属性装写“无被动”即没有附加伤害/盾/治疗表达式、触发事件、内部CD、被动范围、叠层或唯一组；这些被动资格不适用，不暗含隐藏治疗。所有装备仅装备时生效。外观列只给低细节轮廓提示，本任务未生成素材；新增资源接入须ember-art及真实Creator导入/meta。

## 5. 两种具名被动

### 5.1 符击

- 触发：拥有者成功执行主动技能的OnSkillCast，内部CD就绪时获得5秒蓄能，层数1；再次施法刷新有效期、不排队。额外弹体、被动、DOT、拒绝施法不触发。内部CD期间不预存。
- 下次原始直接普攻命中首个合格敌人，附加 `8 + 0.20×总AD + 0.12×AP` **魔法**伤害。AD/AP在该攻击出手采样；穿透和吸血命中读取。蓄能资格出手锁定至该攻击实例；取消/挥空释放锁定但不消耗未过期蓄能。扇形多目标按CollisionWorld稳定命中序只触发首个，不能每目标一次。
- 范围就是本次普攻的实际碰撞范围，不另搜远处目标；增益飞弹也能消费符击。飞弹被墙挡或挥空不消费。有效命中若本体已杀死目标仍消费并进入CD，不对尸体补伤/吸血；免疫不消费，全盾吸收可消费。
- 内部CD3秒，从消费时起计，跨目标共享；不吃急速或秘术冲拳。无目标生命比例、Boss同公式、无需另设Boss比例封顶。
- Hit：`damageType:magic, delivery:proc, canCrit:false, appliesOnHit:false, proc:true, vampEligible:true`。sourceId是实际装备者、targetId为该次攻击受击者，携带攻击rootId/depth+1；伤害必须走CombatEngine。不是把基础/额外AD换名带回来。
- 台风副弹与虚幻武器产生的OnAttackHit不能消费，避免一施法多次触发。唯一组`equipment.spellblade`最多启用一个；未来多来源时按出手采样公式取最高，平值稳定来源ID裁决，不分别拼最高基础和系数。

### 5.2 石息

- 拥有者被敌对伤害结算后实际失HP，且 `0 < hp < .50×maxHealth`、内部CD就绪时，给自己 `18 + .05×maxHealth` **通用盾**，持续3秒。maxHealth触发时采样；由source HSP作用一次。既已低于50%的下一次受伤也可触发，不只认越线。
- 内部CD18秒，从成功施盾时计；不吃急速。非致死、仅自身、无伤害/直接治疗表达式、无额外范围。致死/只打盾/换装截断/阶段恢复/自残不触发；敌方真实伤害可触发。
- 唯一组`equipment.safetyShield`，最多1层；同组取最大盾，平值稳定来源ID裁决。与其他技能盾独立实例/到期；sourceId=targetId=装备者，保留触发root/depth，不能直接写hero.shield。
- 不暴击、不触发OnAttackHit、不吸血、不发OnHeal；死亡之环不能从施盾触发。585HP六件坦克单盾47.25，只在低血且3秒内受到后续伤害时有价值，不能计作永久HP。

两被动状态与内部CD按playerId+唯一组隔离；使用GameWorld.time，暂停/非战斗冻结。卸装失去蓄能与此装备临时盾，重新装备不重置CD、不免费施盾。新关开始清蓄能/装备临时盾并重置CD；恢复点仍是稳定阶段/关起点，保存构筑/购买顺序与规则版本后重建。未来战斗中任意保存才需保存实时CD/锁定，本文不声称支持该功能。

## 6. 代表构筑与重算方法

基线：玩家HP240、总AD20、AP0、双抗0，基础AS与收益系数均1/.7；原始MS421.25经软阈值为420点，以.01格/点得到4.2格/秒。无等级成长或蓝耗。代码与本稿共用ATTRIBUTE_SYSTEM规则，不用旧skillPower百分比。

纸面公式：

```text
AS=min(3,(1+额外AS比例总和)/.7)
普攻原始DPS=总AD×AS×[1+critChance×(2−1)]
火弹原始DPS=(38+.38AP)×(1+haste/100)/1.6
nova原始DPS=(72+.72AP)×(1+haste/100)/13
符击原始DPS上界=(8+.20AD+.12AP)/3
物理或魔法EHP=HP×(1+对应抗性/100)
```

目标30护甲/30魔抗、无抗性削减。普通物理伤害除1.3；持有sageMask时魔法伤害除1.2，其余除1.3。默认火弹/盾/冲刺/nova。全命中、无限时长、单体、无海克斯/治疗削减、攻击与施法无操作互斥；nova只计1人。符击假设每3秒都成功穿插攻击，是可解释上界。暴击为期望值，真实种子序列有短期波动。**这些是算表，不是实战测量或通关保证。**

列表从左到右为购买顺序；购买顺序只决定各部位外观。下表均无形式增益，全部默认挥砍。脚本还包含裸装、1/2/3/5件曲线及6件全武器/全身体/全头部样例。

## 7. 海克斯与循环边界

- 珠光25%暴击与两件18%相加为61%，基础暴伤2；技能只在增益授权的组件暴击，符击不暴击。暴击率截断1，不额外转AD。攻速按统一3次/秒上限，不能因同类6件绕过。
- 重量级读实际来源玩家maxHealth，坦克HP585使其每次17.55伤害，不能按Boss生命算。台风副弹可依其自身规则触发合格攻击特效，但不消费符击；虚幻武器不能把符击变成每个目标每秒1次。秘术冲拳减少技能剩余秒数，不减3/18秒装备CD。
- 符击Hit显式 `proc:true/canCrit:false/appliesOnHit:false/vampEligible:true`；不冒充skill直击触发飞弹/导管。玻璃大炮的真实附伤照原合法规则分组件一次派生，不重复放大已采样AD/AP。保留rootId、depth≤6、预算128和根/规则/目标去重。
- 吸血→死亡之环伤害必须有 `derived-heal` 标签并 `vampEligible:false`，不让环伤再次产生吸血/转伤。不能只依靠深度/预算耗尽才能停止正常反馈。有效治疗才发OnHeal，过量/波间恢复/施盾不触发。HSP不自动放大全能吸血。
- 两装备被动无目标生命比例或处决，无永久叠血/叠AD；普通、精英、Boss公式相同。已有魔法飞弹目标生命比例与比例部分20上限不得随装备变更取消；多玩家DOT按source+status隔离，不能转给最后命中者。
