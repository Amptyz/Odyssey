# 世界观：熄灭之后

更新：2026-10-20。本文记录用户确认的故事前提；画面规范见 [美术风格](ART_DIRECTION.md)，最新选定形象见 [Q版复燃主角](../art-source/rekindled-chibi-v1/README.md)。

## 已确认的故事前提

1. 曾有英雄盗取火种，为人间带来盛世。
2. 火种最终被扑灭，世界陷入黑暗。
3. 残存的一点火星飘至一处无名之地，点燃数具死尸。
4. 这些被点燃的死者就是玩家操控的主角。他们带着对火与燃烧的渴望，开始旅途。

盗火英雄与玩家控制的死者是两个身份，不能擅自合并。多人角色来自同一复燃事件；他们各自生前身份、彼此关系及最终命运尚未设定。无固定职业的玩法继续成立，流派通过余烬与装备形成。

## 已确认的表达方向

- 整体偏黑暗、血腥；人物与世界应能呈现死亡、伤痕和盛世毁灭后的痕迹。
- 画面不能过暗。世界观里的“黑暗”不等于把游戏画面压成看不见的黑色。
- 保留像素风，通过更丰富的像素动作、明确轮廓和层次提升表现。
- 比较两版后，用户最终选择死亡细胞取向的像素方向；哈迪斯取向作为历史比较稿保留。
- 主角已死去很久，基础形象**没有血迹、没有头发、没有五官**。面部用阴影模糊，增加神秘感和代入感。此项针对主角身体与基础衣物，世界整体的黑暗、血腥基调继续成立。
- 2026-10-21确认采用矮胖圆润的Q版形象，保留像素与上述身份约束；多人可选择不同衣料颜色，配色不构成新职业或新剧情设定。
- 基础角色不预设战士、法师、射手等职业。复燃死者是共同身份，基础整身形象固定；装备只改变构筑数值与被动，不改变人物贴图。

## 设计提案与留白

“复燃者 / The Rekindled”是本轮美术工作的临时称呼，不是用户确认的正式种族、职业或游戏标题。“无名墓地”可作为出生环境提案，正式地名仍待设定；原话中的无名地点不据此扩写成已确定的城镇或国家。

干枯灰白尸肤、焦痕、无血的旧裹布、胸口干裂中的少量余火及动作中的趋火欲望属于当前视觉提案。旧候选中的头发、清楚五官和染血布料已被用户否定，不得作为后续主角默认设定。方向与上述限制已确认，新图的精确体型、衣物和余火形状仍可修改；不能将代理生成的新图记成用户已逐项批准。旧两图、怪物、美术与技能设定是现有 Demo 内容，不能自动证明它们在新世界观中的归属。

以下保持开放，不由美术生成器补成正式剧情：火种来源与被扑灭的原因、盗火英雄结局、死者生前身份、复燃是否有代价、为何渴望燃烧、敌对阵营与终局。新称谓、符号或神祇先标为提案。
