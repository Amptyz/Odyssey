## M2：肉鸽闭环

- 三波敌人（5 / 9 / 13）；刷点不在障碍内，离玩家至少 6 世界单位，避开其他出生单位。
- 波次结算冻结逻辑，每次抽取 3 个不同且未持有的增益；第三波也选择奖励，然后进入胜利页。
- 死亡优先于奖励，重开重新建立相同种子的世界。
- 增益按稳定数据顺序匹配事件条件与效果，不为指定组合互相写特殊调用。
- OnHit / OnKill / OnSkillCast / OnStatusTick 携带来源、目标、原因、深度、技能、标签、根事件 ID。
- 先预留事件预算再应用伤害；根事件最多 128 个事件、最大深度 6；规则在同一根事件/目标上去重；死亡标志在伤害时立即设置，杜绝重复击杀。
- 每次事件处理后清空工作队列和去重表，历史限 256 条，视觉事件限 192 条。
- 指定的三组组合均通过核心测试，首页提供对应预设实验入口。

### 50 敌人性能测量

初次使用扫描 open-set 的 A*，平均 0.962 ms/tick，P95 1.744 ms，最大 145.009 ms；保留原始报告 `reports/benchmark-before-path-cache.json`。发现同一帧大量寻路的尖峰后改为**预计算可通行邻接边 + 二叉最小堆**，并增加随机路径逐段碰撞验证。

最终测量（Apple M4 / Node v26.0.0）：

- 平均 **0.0848 ms/tick**，P95 **0.2299 ms**，最大 **7.9963 ms**。
- 每 tick 包含模拟推进和一次完整快照；不包含生成输入命令的时间、Cocos Graphics、文本排版、GPU、浏览器事件或截图。
- 起始 GC 后堆 7,217,680 字节；120 秒模拟后 7,823,896 字节，增量 606,216 字节。
- 每 20 秒采样 GC 后内存：7,717,272 / 7,788,064 / 7,749,440 / 7,767,312 / 7,799,800 / 7,823,896 字节。
- 最终历史 256 条、视觉事件 1 条、投射物 17 枚。没有超出历史/视觉队列上限。
- 为保留 50 敌人的持续负载，此性能夹具人为提高玩家和敌人 HP；**仅此压力夹具**使用高 HP。真实数值通关另由 `playthrough` 验证。
- 本次测量没有发现无界事件队列，但短时 Node 堆测量不能证明长期浏览器无泄漏；**未测得任何真实游戏画面 FPS**。

### 正常数值的自动战斗

机器人只发送标准目标/Q/W/R/选增益命令，不移动 HP、伤害、冷却或死亡标志。未使用 E 躲招；目标选择和增益策略很简单，胜率不代表人工体验。
