# 首批海克斯 · 统一属性版

本轮实现前面选定的 12 个海克斯机制，加入原有 8 个被动的统一三选一奖励池。名称和机制参考海克斯大乱斗，以下是本 Demo 的 **PvE 适配数值**，不是某个英雄联盟版本的逐项复刻。没有导入官方图标、音效或美术资源。

## 试玩

正常“启程整备”仍从零开始，每波两张被动、一张主动技能，选中才获得；已拥有被动不会重复出现。

首页新增三个预装组合，仍使用正常怪物、装备、金币、伤害和技能冷却：

- **法术爆发**：魔法飞弹、珠光护手、炼狱导管、玻璃大炮。
- **普攻联动**：虚幻武器、点亮他们、重量级打击手、秘术冲拳、台风。建议购买长弓，也可以测试近战群体挥击。
- **冲刺续航**：大地苏醒、黎明使者、死亡之环，加上原有嗜战恢复作为另一治疗来源。

按 Esc → 查看本局增益，可以分页阅读完整效果。F3 继续显示角色、障碍与弹体碰撞圈。大地苏醒常规显示淡金色路径轮廓，爆炸时短暂加粗；暴击数字带 `!`。不使用满屏闪光。

## 已实现效果

| 海克斯 | 当前效果与边界 |
| --- | --- |
| 魔法飞弹 | 玩家技能直击命中后，从玩家向命中位置发射 3 枚小角度散射飞弹，整体冷却 0.5 秒。每枚基础真实伤害 `8 + min(实际碰撞目标生命上限 × 0.5%, 20)`，乘以 `1 + min(飞行距离 / 10, 1)`，射程 32 格。不追踪，能被躲开、拦截或被障碍挡住。 |
| 珠光护手 | 25% 暴击率，普攻和技能直接伤害默认暴击倍率 2.0，读取单位 critDamage。每次命中独立判定；持续伤害、海克斯副弹与附伤不暴击。随机流有固定种子，独立于刷怪与奖励抽取。 |
| 炼狱导管 | 技能直击附加导管灼烧，4 秒，每层每秒 4 伤害，最多 5 层。重复附加刷新时长，不重置跳伤节奏。每次跳伤减少全部已装备技能剩余冷却 0.15 秒，整体触发间隔 0.2 秒。与原有燃烧弹的灼烧为两个独立状态。 |
| 虚幻武器 | 技能直击触发一次攻击特效，每个目标间隔 1 秒。当前可联动重量级打击手与秘术冲拳。不会被灼烧、魔法飞弹、尸爆或电弧反复触发，也不计作一次普攻出手。 |
| 点亮他们！ | 每第 4 次实际普攻出手，朝该次鼠标方向额外发射 3 枚飞弹，每枚 12 伤害、射程 28 格。挥空也计数，一次近战打到多人仍只计一次；副弹不增加出手计数。 |
| 重量级打击手 | 攻击特效：对实际命中的目标额外造成当前自身生命上限的 3% 伤害。同次近战对同一目标一次；装备与玻璃大炮对生命上限的变化会影响附伤。此附伤只使用生命比例，不额外添加 AD/AP 系数。 |
| 秘术冲拳 | 攻击特效：全部当前已装备技能剩余冷却减少 0.35 秒，整体触发间隔 0.25 秒；冷却不低于零。普攻挥空或子弹尚未碰撞不会减冷却。 |
| 台风 | 普攻出手时，在 16 格内寻找另一个可见敌人，发射 45% 普攻伤害的副弹。排除主射线上的首个敌人；副弹发射后不追踪、使用正常碰撞，可触发攻击特效。没有另一个候选时不发射。不会改变玩家主普攻的方向。 |
| 大地苏醒 | 冲刺结束后记录实际起终点，0.6 秒后以半径 1.7 格的胶囊体积爆炸，造成 45 伤害。路径被障碍截断，目标可以在延迟期间离开。没有移动技能时不进入奖励候选，换掉移动技能后已拥有的增益保持休眠。 |
| 黎明使者的坚决 | 实际掉血后生命低于 50%，且仍存活时触发；3 秒内每 0.5 秒治疗一次，总量为触发时生命上限的 30%，冷却 45 秒。护盾吸收全部伤害、致命伤害均不触发。 |
| 死亡之环 | 实际有效治疗量的 70% 转成对 10 格内最近可见敌人的伤害；查询考虑目标碰撞半径与障碍。满血溢出治疗、护盾、波间 30 点补给不会触发。可联动黎明使者和嗜战恢复。此伤害只使用有效治疗量，不额外添加 AD/AP 系数，也不可吸血。 |
| 玻璃大炮 | 装备计算完成后，生命上限乘 0.7 并四舍五入；非真实伤害附加其护甲减免前数值的 25% 真实伤害。已有真实伤害不会再次加成。真实部分绕过护甲，但仍由护盾吸收。领取或换装只截断超出的当前生命，不凭空回血。 |

统一属性迁移后，已移除全局 skillPower 倍率。点亮他们、导管灼烧、大地苏醒按配置固定伤害结算；台风读取普攻比例，重量级读取自身生命比例，死亡之环读取有效治疗比例。固定伤害不自动获得 AP 加成；新增系数必须使用显式表达式。普通普攻是物理伤害，未指定类型的这些派生伤害为魔法伤害，魔法飞弹为真实伤害；玻璃大炮为非真实伤害追加独立真实分量。

## 扩展入口与触发约定

- `content/perks.ts`：配置、文案、数值、奖励要求、试玩组合；`PerkId / LabId` 从配置推导。
- `combat-core/types.ts`：新增 `OnAttack / OnAttackHit / OnHeal / OnDamaged / OnDashEnd` 事件与效果原语。规则支持 `cooldown / perTarget / every / directOnly / tags / healthBelow`，新组合尽量只加配置。
- `CombatEngine`：只管理规则队列、确定性暴击、规则计时、治疗、延迟范围；通过 `CombatHooks` 请求发射弹体、读取普攻伤害、扣减技能冷却，不依赖 Cocos 或 GameWorld。
- `EffectHandlers`：效果实现与穷尽类型检查。附伤明确携带 `proc`，只有台风明确携带 `appliesOnHit`，防止副弹被当成新的普攻出手或技能直击。使用 `damageType` 明确物理 / 魔法 / 真实类型，`delivery / area / canCrit / vampEligible` 表明结算资格；旧 Hit.trueDamage / unscaled 已移除。
- `StatusSystem`：减速来源独立计时、取最强，强者结束回退弱者；灼烧按 sourceId + status 保留归属，导管每来源独立最多 5 层。可以添加同类叠层状态而不用给角色硬编码字段。
- `GameWorld`：所有海克斯弹体进入同一个连续碰撞更新。真实冲刺结束后发事件，快照输出延迟范围；换装 / 获得被动时从基础装备属性重新计算最大生命。
- `validateContent`：验证效果引用、数值、弹体形状、计数、冷却和试玩预设。

同一根触发链仍受 128 事件、深度 6、同规则同目标去重保护。治疗派生的伤害和击杀继续保留根事件；死亡之环标记 derived-heal 且不可吸血，派生治疗不能再触发同类环，避免治疗反馈。延迟弹体是新碰撞事件，但其 `proc` 来源阻止重新生成该类触发弹体；海克斯发射时也受总弹体数量 256 的保护。

暂停、商店、奖励阶段冻结时间。每波开始重置触发冷却、普攻计数、持续治疗、延迟范围和奥能储备；保留已获得增益。波间补给是阶段恢复，不属于战斗治疗。重开创建全新世界。

## 验证

`pnpm check` 覆盖类型与所有纯逻辑回归；`tests/combat-core/hexes.test.ts` 和 `tests/simulation/hexes.test.ts` 覆盖 12 种效果、混合联动、碰撞、暂停、装备重算、奖励池和固定步进一致性。

Cocos Web Desktop 构建后运行 `pnpm test:hexes`，使用真实鼠标键盘访问三个预设、购买装备、攻击施法、查看说明，验证飞弹、暴击、灼烧、延迟范围和低血量治疗转伤害。页面只开放已有调试快照读取，没有测试专用伤害、回血或赋予增益命令。

`pnpm playthrough` 继续记录普通数值的 10 个种子。玻璃大炮有实际生存代价，自动玩家并不保证所有构筑都通关。性能基准为独立耐久夹具，双方使用极高生命以维持 50 敌人的 120 秒持续战斗，不能当作正常玩法战绩。
