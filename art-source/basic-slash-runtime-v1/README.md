## 实际实现

- `render/MeleeVfxPlan.ts`：纯表现时间线和七层曲线带。共享一套几何形态，使用每次Swing的中心、方向、半径与角度，不复制方向资源。宽厚圆钝斩头最亮，后方光流逐渐细、暗、透明；没有外围散点。
- `render/MeleeVfxView.ts`：每个渲染帧绘制，目标60 Hz显示；从30 Hz模拟快照的余量插值出额外姿态，实际帧数依设备而定。保持既有0.12秒前摇 / 0.12秒有效期和攻速规则。没有把伤害模拟改成60 Hz，也不是60张手绘身体帧。
- 有效范围层在角色下方显示完整扇区，亮锋 / 内部光流在上方。只按真实相位切换生效状态，插值不提前打开范围；结束即撤有效边界，低亮余迹最多保留0.12秒。
- 同一CollisionWorld遮挡查询裁剪外缘与每层光流，等比例地面不压扁；按实际射程缩放，不按人物贴图尺寸计算伤害。
- CombatEngine的真实伤害cue附带sourceId / attackId，只有对应近战命中才产生短白色爆点。挥空不产生爆点；数字、技能和远程普攻保留已有路径。
- 暂停冻结，提前取消 / 死亡 / 场景切换 / 重开清理；余迹固定最后合法中心和方向。敌方危险提示最后绘制，避免被友方光流盖住。

## 验证入口与边界

运行`pnpm check`、`node --import tsx scripts/browser-melee-vfx.mjs`及`pnpm test:hitboxes`。浏览器报告为[运行检查](../../reports/melee-vfx/runtime.json)，包含普通营地 / 余烬 / 出发后的鼠标普攻，以及显式F2测试里的方向、暂停、射程、攻速与命中检查；画面与录像同目录保存。

这是代码原生特效生产，不声称严格像素网格、独立手绘序列帧或四人GPU压力测试已完成。角色本体继续使用原整身近战帧；新的身体动作精修、停姿、镜头与音效属于ART-15。火 / 冰 / 黑暗映射属于ART-14，默认效果保持中性灰白。
