## 目录与再生成

- [人物装备记录](hero-equipment/QA.md)、[环境特效记录](environment-vfx/README.md)、`monsters/`：原始输出、Prompt、测量与选取依据。
- `manifest.json`：补丁定义入口，按顺序覆盖 `../pixel-production-v1/production.json` 的稳定ID；新ID追加。
- 定义使用 `frames: [{rect:[x,y,w,h], anchor:[x,y]}]`，人物批次兼容别名 `explicitFrames`；坐标是原PNG左上角像素矩形，anchor从裁切帧左下角归一化。`scale`可固定身体比例。
- 生成命令：`python3 scripts/inspect-pixel-art.py`；检查命令增加 `--check`。需要 Pillow。只读PNG，生成 TypeScript / JSON，不能编辑图片。
- 原始RGBA由内置image_gen产生，运行文件原样复制；新 `.meta` 由 Creator3.8.8真实导入生成。候选留存不意味着已在运行时使用。

## 验收范围与限制

实际结果统一记入 `reports/art-completion-validation.json`，浏览器记录见 `reports/browser-art.json`。正常商店与显式F2测试分开描述，截图不代表自然通关或多人压力通过。

这是一批可运行的像素风素材，尚未严格满足64×64逻辑网格、24–32色或二值alpha。AI输出包含低alpha边缘和较多颜色；最近邻采样不能替代人工像素整理。地图地面/水面、弹体核心、雷电/治疗/雾与部分敌方效果保留Graphics；没有为每个增益制作独立纹理，也没有Spine或八向动画。完整危险范围继续来自模拟碰撞，装饰帧不会扩大命中。
