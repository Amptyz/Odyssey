# 初始近战挥击：关键帧设计 v1

此版已被用户指出力量感不足，保留作历史比较。当前制作方向见[v2力量感修订](../basic-slash-v2/README.md)，不要继续以本版的细斩弧为生产目标。

2026-10-21。用户希望初始普通近战攻击共用一个基础效果，通过粒子和颜色表现火、冰、黑暗等变化。本次为概念设计交付，尚未替换运行时特效或实现新粒子系统。
