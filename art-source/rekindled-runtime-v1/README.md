# 复燃主角运行素材 v1

> 已停用：用户随后改为完整身体序列帧并取消装备换皮；此处保留十部件方案的制作历史。当前入口为[整身角色](../whole-hero-v1/README.md)，不要恢复本批次的关节或装备叠层。

2026-10-20。身份参考：`../rekindled-hero-v3/concept.png`。本批是实际透明部件与运行骨架，未裁切设计海报。基础主角无血、无发、无五官；灰白干枯尸肤、深色旧布、微小胸口余火。

## 文件与来源

- `parts-v1.png`：内置 image_gen 输出原件，1536×1024 RGBA，五个绘制视角，每视角十个部件。工具输出原路径记录在 `production.json`。PNG 像素未被脚本改写。
- `atlas-definitions.json`：实测 50 个 SpriteFrame 矩形；由既有 `scripts/inspect-pixel-art.py` 生成 `content/pixel-art.ts`，在 `art-source/art-completion-v2/manifest.json` 注册。
- 运行文件：`EmberDemo/assets/resources/art/rekindled-v1/parts.png`，内容与源 PNG 相同；`.meta` 由 Creator 3.8.8 实际导入生成。
- 透明度和 hash 的可复跑分析在 `art-source/art-completion-v2/inspection.json` 的 `rekindled` 项。

视角按向屏幕下、右下、右、右上、上排列；另外三个左向视角由相应右向整体镜像。方向依游戏投影计算，未修改物理移动、碰撞、攻击时刻或投影。十部件依次为头、躯干、左上臂、左前臂与手、右上臂、右前臂与手、左大腿、左小腿与脚、右大腿、右小腿与脚。图中大腿带有多余的上部衣摆，切片只选择裤腿和膝部；这属于 SpriteFrame 选择，没有抠图或重绘。

## 动作与换装

`HeroRig` 从旧六部件刚性摆动升级为可屈肘、屈膝的十部件骨架。行走 1.65 个完整左右循环/秒，跑步 2.5 个/秒，每个循环两次交替支撑与收腿；当前正常移速使用跑动，慢速状态可以使用行走。视图按插值模拟时间连续采样，保留暂停冻结，不使用真实时钟决定姿态。取消人物 15° 角度量化，以连续关节角度减轻跳变。不是 50 张逐帧动作，也不是将三四张关键姿加速；它是五视角贴图搭配实时骨骼动画。

近战、远程、施法、待机、受击和死亡均使用同一新主角。近战有肩肘展开，远程/施法有抬臂，受击有短反冲，死亡沿模拟死亡年龄倾倒；不从动画回调产生伤害。

六通用装备栏、购序和实际属性逻辑不变，表现仍由已有 `EquipmentAppearanceLoadout` 选择 weapon/body/head。武器挂点成为前臂下的掌心节点，头饰跟随头部，衣甲覆盖肩缝。**本批没有重绘 18 件装备的五视角图**：沿用旧单视角装备，并做尺寸/侧向缩窄与前后遮挡适配；背面衣甲和头饰仍可见原单视角装饰，是明确的美术限制。

## 质量边界

生成图有真实 alpha（超过百万个全透明像素），但大量边缘为分数 alpha；不是严格二值透明。原图的颜色数量和逻辑像素网格尚未达到严格 24–32 色/统一 texel 标准。运行时最近邻采样、缩小显示与连续旋转有混合像素密度。此次优先实现身份、方向、流畅的肢体动作和换装，不能把这些限制称为严格像素生产验收已通过。

测试与实际构建证据见 `verification.md`；截图与录屏在 `reports/rekindled/`。顶层美术文档由主会话汇总更新。
