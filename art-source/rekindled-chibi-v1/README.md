## 设计取向

- 保留像素表现，以大圆头、宽短躯干、短粗四肢与低重心形成矮胖轮廓；通过整身姿势表达性格。
- 延续无血、无发、无五官的复燃死者身份：灰白尸肤、阴影面部、暗灰紫裹衣、旧赭色腰带与局部小余火。
- 形象不绑定职业，装备不改变身体贴图；头、躯干和四肢保持完整相连。
- 设计板包含主视图、不同角度、跑动与蓄势姿态、小尺寸场景示意。正面标注的实际姿态偏三分之四，不能用作严格正交转面图；两张动作姿态不是动画循环，场景示意不是游戏截图。
