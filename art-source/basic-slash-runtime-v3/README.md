# 普通近战：原稿帧序与移动亮锋判定

> 2026-10-22最新变更：半圆方案被后续实测曲面替代。图片、判定、F3共用原图材质测量的动态轮廓与相位，填到人物中心保留贴身命中，取消固定180°裁剪。以下移动亮锋 / 原始窗口说明仅为v3历史；当前规则及测量见[基础近战规格](../../docs/design/BASIC_MELEE_VFX.md)。

2026-10-21。用户否定 runtime-v1 / v2 的实机造型，要求与已确认的 [v7 关键帧](../basic-slash-v7/keyframes.png)一致，并明确选择“按定稿环扫，并同步修改判定”。本版直接播放该原稿的帧序，不再把另一张直条光流弯成旧扇区。

## 资源来源与采样

- `keyframes-source.png` 为 v7 原图的原样副本，1448×1086 RGB；运行副本为 `EmberDemo/assets/resources/art/melee-v3/keyframes-source.png`。与用户本轮附件的 RGB 像素完全相同，两个仓库副本字节相同，SHA-256：`9d21873c18bb95ba7410b56b1a4b7ad90e5dd1323e75d07a9176b406c293c886`。
- 本次没有生成另一版刀光，也没有修改原 PNG。原始生成记录和 Prompt 保留在 [v7](../basic-slash-v7/README.md)。源图仍含黑底和标注；它不是透明生产图集。运行材质只采样画面窗口，标注与分格线不会显示。
- `content/melee-motion.ts` 登记四列 x=`3,365,727,1089`，三行 y=`90,423,756`；各格固定 `356×282`，共同原点 `(178,138)`，参考半径 `180`。不可逐帧按包围盒对齐或缩放。
- `effects/melee-keyframes.effect` 在运行时以源背景亮度 `35/255` 为基准，将原图灰度光流转为白色光的 alpha：`clamp((luminance - 35/255) / (1 - 35/255), 0, 1)`。这是合成规则，不是已经恢复了原始独立 alpha；极暗背景附近的细节会被去除，浅底上的对比度也与黑底稿不同。
- 关键时刻为 `0,80,120,144,168,192,216,240,270,300,330,360 ms`。关键时刻直接采样对应原画；间隔采用局部亮锋位置对齐后的双帧混合，减少两个亮头同时出现。旧尾迹与角色支点不跟随亮头平移。没有声称生成了 60 张手绘帧。

## 世界几何与判定

默认近战使用定稿的环绕轨迹；**不是整圈同时伤害，也不是旧扇区全域伤害**。`MELEE_BLADE_KEYS` 保存亮锋的归一化世界轮廓；`MeleeSweep` 根据实际 Swing 的相位、中心、朝向和半径生成当前多边形，并扫掠两次模拟更新之间的路径。轮廓是内容配置，运行时不读取 PNG 像素判定。

`GameWorld` 将这些世界形状交给 `CollisionWorld`，仍按目标碰撞体积、地形遮挡和每刀 `hitIds` 处理，经 `CombatEngine` 结算。只有亮锋扫到的区域有效；内部空洞、旧尾迹和结束余迹不造成额外伤害。同刀同目标最多一次，各玩家的攻击来源保持独立。F3 显示当前亮锋与上一模拟步的扫掠范围。

图片整体以鼠标方向连续旋转，标准朝向是屏幕向上；世界方向先经 GroundPlane 转换。统一缩放采用 `Swing.radius / 180`，默认基础射程仍为 5。`arc` 记录环绕尾迹的近似角度，不能再用它构造整块伤害扇区。图像的自由曲线不会改变地面度量或引入上下移速补偿。

原稿尾迹通过半径与地形 Stencil 裁剪；这个遮罩只限制可显示区域，不代表整个圆都能伤害。灰色范围底板、黑色扇形线框及旧 v2 纹理 / 材质已移出运行资源。

## 时间与生命周期

普通速度仍为 0.12 秒前摇、0.12 秒生效，最多 0.12 秒结束余迹；高攻速读取实际 Swing 时长。前摇保持暗痕，不能提前播放亮锋。渲染插值不推进伤害；实际命中爆点只读带 sourceId / attackId 的伤害事件。暂停冻结，提前取消不冒充自然完成，重开 / 换图清理；自然完成后的尾迹保留最后合法位置和角度。

2026-10-21 对齐修复：刀光的年龄与中心在 `previousAge / previousCenter → age / center` 之间插值，和单位位置使用同一个已完成的模拟步。禁止使用 `age + alpha × FIXED_DT` 预测尚未判定的未来亮锋，否则快速环扫会出现明显角度领先、看似碰到而尚未扣血。最后一个模拟步移除 Swing 后，先播放该步尚未显示完的有效片段，再进入余迹。F3 实线读取当前显示相位的同源亮锋，淡线表示已结算的步间扫掠；红色扇形仍属于敌人预警。
